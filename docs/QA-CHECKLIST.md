# Regression QA

- Open and close every navigation item without page freeze.
- Create a new AI chat and verify media from the previous chat is absent.
- Generate text after an image and verify the text does not overlay the image.
- Verify send is disabled while a request is already submitting.
- Test model failure and fallback behavior.
- Test Videos, Lessons, Assignments, Groups, PDFs, Dictionary, Profile and Settings independently.
- Test dark and light modes independently from color themes.
- Test Android/mobile keyboard, composer and send button placement.
- Test signed-in header and account state.
- Test slow and failed network requests for usable loading/error states.
